# Тестирующая система

Telegram бот для создания и прохождения тестов с системой статистики и управления пользователями.

## Требования

- Python 3.8+
- Docker и Docker Compose
- PostgreSQL

## Установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
```

2. Активируйте виртуальное окружение:
- Windows:
```bash
.\venv\Scripts\activate
```
- Linux/Mac:
```bash
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

### Локальный запуск

1. Запустите PostgreSQL через Docker:
```bash
docker-compose up -d db
```

2. Запустите бота:
```bash
python bot_main.py
```

### Запуск через Docker

1. Соберите и запустите контейнеры:
```bash
docker-compose up --build
```

## Основные функции

- Создание и редактирование тестов через админ-панель
- Прохождение тестов через Telegram бота
- Просмотр результатов и статистики
- Управление пользователями
- Система ролей

## Структура проекта

```
Praktika/

├── tests/         # Тесты

```

## Основные компоненты

### Telegram бот
- Обработка команд пользователей
- Прохождение тестов
- Просмотр результатов
- Управление профилем

### Админ-панель
- Создание и редактирование тестов
- Управление пользователями
- Просмотр статистики
- Настройка системы

## База данных

Проект использует PostgreSQL с Alembic для миграций. Основные таблицы:
- users - пользователи системы
- tests - тесты
- questions - вопросы
- answers - ответы
- results - результаты прохождения тестов

## Безопасность

- JWT аутентификация для админ-панели
- Ролевая система доступа
- Безопасное хранение паролей
- Защита от SQL-инъекций
